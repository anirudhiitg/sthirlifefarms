# AGENTS.md: Sthir Life Farms - UI/UX & Aesthetic Guidelines

**Project Context & Brand Philosophy**
This repository builds the digital sanctuary for **Sthir Life Farms**[cite: 10]. The core philosophy is rooted in mindfulness, sustainability, and slowing down in a frantic world[cite: 10]. The digital experience must reject aggressive e-commerce patterns and instead act as an unhurried, grounded manifesto[cite: 10]. Every component, animation, and layout must reflect our core mantra: *"Stay Still. Live Whole."*[cite: 7, 8, 10].

## 1. Color Palette (The Earthy Aesthetic)
Do not use stark white (`#FFFFFF`) or pure black (`#000000`) for large background or text areas, as they create digital harshness. Use the following exact hex codes:
*   **Kraft Beige (`#E8E0D5`):** Use as the primary background color[cite: 10]. This soft, calming tone resembles unbleached paper[cite: 10].
*   **Forest Green (`#2C4637`):** Use for primary buttons, active states, and key iconography[cite: 10]. This deep, grounding color matches our botanical wax seals and the logo background[cite: 7, 8, 10].
*   **Warm Terracotta (`#B45F44`):** Use for subtle accents, secondary borders, or hover states[cite: 10]. This rich, earthy tone reflects the sun-baked soil of our Rajasthan farm[cite: 10].

## 2. Typography System
Balance heritage with modern simplicity by utilizing a strict two-font system[cite: 10]. 
*   **Primary Font (Serif) - *Cormorant Garamond* or *Playfair Display*:** Use for all main titles, headers, and pull quotes (like *"Stay Still. Live Whole."*)[cite: 10]. Apply Semi-Bold or Medium weights in ALL CAPS with slight letter spacing for main titles, and italicize for quotes[cite: 10]. 
*   **Secondary Font (Sans-Serif) - *Montserrat* or *Lato*:** Use for body copy, product descriptions, subtitles, and form fields[cite: 10]. Apply Light or Regular weights with generous line height (1.5 spacing) for breathability and readability on mobile[cite: 10].

## 3. Visual & UI Components
*   **Minimalism & Whitespace:** Implement ample padding and margins. The interface should feel incredibly clean and unhurried[cite: 10].
*   **Buttons & Calls to Action (CTAs):** Do not use aggressive language like "Buy Now" or "Hurry"[cite: 10]. Use phrases like "Request an Invite", "Apply for Membership", or "Order via WhatsApp"[cite: 10]. Style buttons with soft corners, Forest Green backgrounds, and Kraft Beige text.
*   **Imagery Framing:** Images should be presented cleanly, reflecting our premium wabi-sabi aesthetic—featuring elements like raw linen, unbleached kraft paper, dark wooden lids, and green botanical wax seals[cite: 8, 10].

## 4. Animations & Interactions
*   **Pacing:** All animations must be slow, deliberate, and smooth. Avoid bouncy, elastic, or rapid transitions.
*   **Effects:** Use gentle fade-ins (`opacity` transitions) for page loads and soft color shifts for hover states. 
*   **Scrolling:** Ensure smooth scrolling behavior across the manifesto sections.
